# Modernization acceptance

The user's 2026-11-06 direct-work policy replaces the earlier copy-only protocol. Historical task records describe their original checks, not future worker instructions.

Every task requires the full controller checks, an independent implementation review and primary final acceptance. Implement directly, iterate with focused checks, then run the full suite when ready. Preserve scope, writer leases, deadlines, memory limits, protected content and production boundaries.

Do not judge acceptance by a worker command log, frozen artifact identity or Codex environment warnings. An actual failed check or actionable review finding requires a repair. Keep one commit and a short progress note per accepted task. Delete its baseline output and run logs after acceptance, keeping the event log and unfinished work. Continue between batches; record hardware, accounts and decisions as blockers.
