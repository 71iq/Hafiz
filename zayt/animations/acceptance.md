# Zayt v3.1 production checks

The runtime set contains 11 animations, 11 posters and the A01 S still. All 23 files fit. A02 is a review clip, not the intention asset. This branch produces art. It does not change what a released Hafiz screen displays.

Review the [gallery](gallery.html) offline. The [size report](size-report.json) records container checks, hashes, encoder trials and comparisons for every file. [Review measurements](review-metrics.json) gives the exact source-pixel coordinates for the colour and alpha checks below. Fable's 6/10 score applies to the earlier renders. This pass has not been rescored by Fable or tested on a physical phone.
